# University of Waterloo Faculty Map
In an effort to learn more about API's I created a rudimentary map of my university, separating buildings by their faculty. 

This project posed many challenges. Navigating new software such as the Google Cloud Console and overcoming obstacles while coding my first website made the result of this project extra rewarding!

# Specs:

Purpose: Fun interactive UW campus map depicting buildings that belong to each faculty 
API: Obtained API key from Google Cloud Console using the Maps JavaScript API

Concepts: 
* JavaScript event listeners
* Arrays and objects
* Dynamic marker creation
* Marker visibility filtering
* Google Maps coordinates and map controls
* Custom Icons and visual branding

Future Improvements: 
* Build detailed pop-ups for each building
* Accessibility information
* Mobile-friendly map controls
* More accurate data
